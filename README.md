# Točak 1E

Točak sa imenima iz 1E.

- **Točak:** `index.html` — otvori ga na kompjuteru u učionici i pritisni **Zavrti** (ili Space, ili klikni na točak).
- **Kontrola:** `z7/` — za sat ili telefon. Link `z7/#šifra` otvara bez kucanja šifre.
  - Dodirni ime → namešteno. Ako se točak vrti, menja ovaj spin; ako ne, važi za sledeći.
  - Dole: trajanje, "samo jednom / za svaki spin" i ko ne sme da bude izvučen.

Točak i kontrola se povezuju preko [ntfy.sh](https://ntfy.sh) (besplatno, bez naloga).

## Izmene

- Imena: `shared.js` → `NAMES`
